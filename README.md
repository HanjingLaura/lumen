# Lumen

Configurable ambient scenes driven by physical keys over BLE.

- Web scene engine + button↔scene mapping (frontend)
- BLE Notify ASCII: `SCENE:<id>\n` (id 1–4)
- Device name prefix: `Lumen-xxxx`
- Mock four keys for UI work without hardware
- Optional later: mic / candle / haptic

New clean repo. Former `goblin-candle-summon` narrative assets are not carried over.
